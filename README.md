# FRC Pre-Match Checklist-ARC 6014
This is a Java command line app I built for FRC Team ARC 6014 to make sure that the robot and the team is fully ready before the match.

What it does
1-You build a custom checklist for whatever your team needs to check.
2-It makes sure that you go through every single item without skipping.
3-You enter the voltage and health data of 3 batteries and t picks the best battery (closest to 13V, battery health breaks the tie).
4-If something isn't done, it won't let you continue until you do it.

How to run it
1.Make sure you have Java installed
2.Compile: "javac Main.java"
3.Run: "java Main"
